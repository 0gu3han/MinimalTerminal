19.1 Introduction to the Standard Template Library

Introduction to the Standard Template Library

  • The Standard Template Library (STL) contains templates organized into three main categories:
  • Containers: Class templates for objects that store and organize data
  • Iterators: Class templates for objects that behave like pointers, used to access individual data elements
  • Algorithms: Function templates that perform various operations on container elements
  • The STL provides the foundation for most modern C++ applications, saving time and reducing bugs.

19.2 STL Container and Iterator Fundamentals

STL Container and Iterator Fundamentals

  • A container is an object that holds a collection of values or other objects
  • An iterator is used to access and traverse the elements
  • Sequence Containers: Store data sequentially in memory (array, vector, deque, list, forward_list)
  • Associative Containers: Store data for fast key-based lookup (map, multimap, set, multiset)
  • Key Point: Containers must include appropriate header files (<vector>, <map>, <set>, etc.) and use the std namespace.

The array Class

  • A traditional C++ array enhanced with bounds-checking and useful member functions
  • Fixed size known at compile time
  • Defined in <array> header
  • Syntax: array<Type, Size> arrayName;
  • Member functions: at(), front(), back(), size(), fill()

#include <iostream>
#include <array>
using namespace std;

int main() {
    array<int, 5> numbers = {10, 20, 30, 40, 50};
    cout << numbers.at(0) << endl;    // Safe access
    numbers.fill(99);                 // Set all to 99
    cout << numbers.back() << endl;
}

Iterators: Uniform Container Access

  • Iterators provide a consistent way to access elements in any STL container, regardless of internal structure.
  • Forward: Move forward only (++)
  • Bidirectional: Move forward or backward (++, --)
  • Random Access: Jump to any element
  • Input/Output: Work with streams
  • Think of iterators as bookmarks that can move through container elements!

Iterator Operations

  • Iterators work like pointers and support similar operations:
  • * operator: Dereference to get element value
  • -> operator: Access object members
  • ++ operator: Move to next element
  • -- operator: Move to previous element (bidirectional)
  • == and != operators: Compare iterators

#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    vector<string> names = {"Alice", "Elana", "Yuki"};
    auto it = names.begin();
    cout << *it << endl;     // Displays "Alice"
    it++;                    // Move to next element
    cout << *it << endl;     // Displays "Elana"
}

const_iterator

  • A const_iterator prevents modification of container elements while allowing traversal.
  • Use cbegin() and cend() member functions
  • Cannot modify elements through a const_iterator
  • Compiler enforces read-only access
  • Use auto keyword for cleaner code

#include <iostream>
#include <array>
#include <string>
using namespace std;

int main() {
    array<string, 3> cities = {"Tokyo", "Paris", "Mumbai"};
    for (auto it = cities.cbegin(); it != cities.cend(); it++)
    {
        cout << *it << endl;    // OK - reading
        // *it = "NewCity";     // ERROR - cannot modify
    }
}

Reverse Iterators

  • Reverse iterators traverse containers from end to beginning.
  • rbegin(): Points to last element
  • rend(): Points before first element
  • crbegin() and crend(): const versions

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {1, 2, 3, 4, 5};
    // Display in reverse order
    for (auto it = numbers.rbegin(); it != numbers.rend(); it++)
    {
        cout << *it << " "; // Displays: 5 4 3 2 1
    }
}

19.3 The vector Class

The vector Class

  • Advantages over Traditional Arrays:
  • Automatically adjusts size as elements are added or removed
  • Provides bounds-checking with at() member function
  • Reports its own size with size() member function
  • Can be initialized with values or created empty

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {1, 2, 3};
    numbers.push_back(4);     // Add to end
    cout << numbers.size();   // Output: 4
}

Key vector Member Functions

  • push_back(value): Add element to end
  • pop_back(): Remove last element
  • insert(iterator, value): Insert at specified position
  • erase(iterator): Remove element at position
  • clear(): Remove all elements
  • empty(): Check if container is empty
  • emplace_back(args...): Efficiently construct element in-place
  • Note: Emplace functions are more efficient than insert/push_back for complex objects!

19.4 The Map Classes

The Map Classes

  • Each element in a map has two parts: a key and a value. Keys are used to locate specific values.
  • Think of a map like a dictionary: words (keys) mapped to definitions (values).
  • map: Sorted, unique keys only
  • multimap: Sorted, allows duplicate keys
  • unordered_map: Fast lookup, not sorted
  • unordered_multimap: Fast lookup, duplicate keys allowed

#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<int, string> employees;
    employees[101] = "Alice";
    employees[102] = "Elana";
    cout << employees[102] << endl;
}

Accessing Map Elements

  • Maps provide multiple ways to access and modify elements:
  • [ ] operator: Creates an element if the key doesn't exist
  • at() function: Throws an exception if the key is not found
  • find() function: Returns an iterator, or end() if not found
  • count() function: Returns 0 or 1 (for map)

#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<int, string> employees = {{101, "Alice"}, {102, "Elana"}};
    // Access using []
    cout << employees[101] << endl;    // "Alice"
    // Check if key exists
    if (employees.count(103) > 0)
        cout << "Found!" << endl;
}

Iterating Through Maps

  • Map iterators provide access to both keys and values using first and second members.
  • Elements automatically sorted by key
  • it->first accesses the key
  • it->second accesses the value
  • Use auto for cleaner code

#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<int, string> employees = {{101, "Alice"}, {102, "Elana"}};
    for (auto it = employees.begin(); it != employees.end(); it++)
    {
        cout << "ID: " << it->first << " Name: " << it->second << endl;
    }
}

Map insert() and erase() Functions

  • Adding and removing elements from maps:
  • insert(): Add key-value pairs
  • erase(key): Remove element by key
  • erase(iterator): Remove element at iterator position

#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<int, string> employees;
    // Insert elements
    employees.insert({101, "Alice"});
    employees.insert(make_pair(102, "Elana"));
    employees[103] = "Yuki";                   // Alternative syntax
    // Erase elements
    employees.erase(102);                      // Remove by key
    cout << employees.size();                  // Output: 2
}

19.5 The Set Classes

The Set Classes

  • Sets store collections of unique values. They automatically prevent duplicates.
  • set: Sorted, no duplicates
  • multiset: Sorted, allows duplicates
  • unordered_set: Fast operations, not sorted, no duplicates
  • unordered_multiset: Fast operations, not sorted, allows duplicates
  • Key operations: insert() adds, find() locates, erase() removes elements

Set insert() and Duplicate Handling

  • Sets automatically reject duplicate values - attempting to insert duplicates is safe but has no effect.
  • Elements automatically sorted in ascending order
  • insert() returns pair<iterator, bool>
  • Second value is true if insertion succeeded, false if duplicate

#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> numbers;
    numbers.insert(10);
    numbers.insert(20);
    numbers.insert(10);     // Ignored - duplicate
    // numbers now contains: {10, 20}
    cout << numbers.size(); // Output: 2
}

Searching Sets: find() and contains()

  • Sets provide efficient searching for element membership:
  • find(value): Returns iterator to element, or end() if not found
  • contains(value): Returns true/false (C++20)
  • count(value): Returns 0 or 1 for set, can be higher for multiset

#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> numbers = {10, 20, 30, 40, 50};
    // Using find()
    auto it = numbers.find(30);
    if (it != numbers.end())
        cout << "Found: " << *it << endl;
    // Using contains() (C++20)
    if (numbers.contains(30))
        cout << "30 is in the set" << endl;
}

Removing Elements from Sets

  • Sets provide multiple ways to remove elements:
  • erase(value): Remove element by value
  • erase(iterator): Remove element at iterator position
  • clear(): Remove all elements

#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> numbers = {10, 20, 30, 40, 50};
    // Remove by value
    numbers.erase(30);
    // Remove using iterator
    auto it = numbers.find(40);
    if (it != numbers.end())
        numbers.erase(it);
    cout << numbers.size(); // Output: 3
}

19.6 The tuple Class

The tuple Class

  • CONCEPT: A tuple is a container that can hold multiple values of different types.
  • Multiple Types: Store different data types in a single object
  • <tuple> Header: Must #include <tuple> to use tuples
  • Fixed Size: Number of elements set at compile time
  • get<N>() Access: Retrieve elements by index or type

#include <iostream>
#include <string>
#include <tuple>
using namespace std;

int main() {
    tuple<int, string, double> student(101, "Alice", 3.85);
    cout << get<0>(student) << endl;    // Displays 101
    cout << get<1>(student) << endl;    // Displays Alice
}

Creating Tuples

  • There are several ways to create a tuple in C++:
  • Using make_tuple, constructor initialization, auto with make_tuple, and braced initialization (C++11)
  • Tip: When using auto with make_tuple, the compiler automatically deduces the tuple's data types. This is often the simplest way to create a tuple.

#include <iostream>
#include <string>
#include <tuple>
using namespace std;

int main() {
    // Using make_tuple
    tuple<int, string, double> itemTuple;
    itemTuple = make_tuple(123, "USB Cable", 8.99);
    // Constructor initialization
    tuple<int, int, int> nums(10, 20, 30);
    // Using auto with make_tuple
    auto gradeTuple = make_tuple(97, 'A');
    // Braced initialization (C++11)
    tuple<string, int, double> info{"Maria Lopez", 21, 3.85};
    cout << get<0>(info) << endl;
}

Retrieving Items by Index from a Tuple

  • Use the get function with an index inside angled brackets to retrieve a value. Indexes start at 0.
  • Index 0: 123 (int)
  • Index 1: "USB Cable" (string)
  • Index 2: 8.99 (double)

#include <iostream>
#include <string>
#include <tuple>
using namespace std;

int main() {
    tuple<int, string, double> itemTuple(123, "USB Cable", 8.99);
    int itemNumber = get<0>(itemTuple);      // 123
    string itemName = get<1>(itemTuple);     // "USB Cable"
    double itemPrice = get<2>(itemTuple);    // 8.99
    cout << get<1>(itemTuple) << endl;       // Displays: USB Cable
}

Retrieving Items by Type

  • If all values in a tuple have different data types, you can retrieve values by specifying the type instead of the index.
  • Warning: Duplicate Types - If more than one value has the same type, you cannot retrieve by type. Use the index instead.

#include <iostream>
#include <string>
#include <tuple>
using namespace std;

int main() {
    tuple<int, string, double> itemTuple(123, "USB Cable", 8.99);
    string itemName = get<string>(itemTuple);    // "USB Cable"
    cout << get<double>(itemTuple) << endl;      // Displays: 8.99

    tuple<int, int, int, double> nums(1, 2, 3, 4.5);
    // cout << get<int>(nums) << endl;    // ERROR! Multiple ints
    cout << get<double>(nums) << endl;    // OK: only one double
}

Modifying the Contents of a Tuple

  • Once a tuple is created, its contents can be modified using the get function on the left side of an assignment operator.
  • You can modify by index or by type
  • You can assign one tuple to another if they have the same number and types of elements
  • A compiler error will occur if the tuples do not have the same number of elements.

#include <iostream>
#include <tuple>
using namespace std;

int main() {
    tuple<int, int, int> nums(1, 2, 3);
    get<2>(nums) = 99;          // Modify by index
    // nums now contains: 1, 2, 99
    auto grade = make_tuple(90, 'A');
    get<char>(grade) = 'B';     // Modify by type
    // grade now contains: 90, 'B'
    tuple<int, int, int> numbers2;
    numbers2 = nums;            // numbers2 now holds: 1, 2, 99
    cout << get<2>(numbers2) << " " << get<char>(grade) << endl;
}

Swapping Tuples

  • The tuple class has a member function named swap that exchanges the contents of two tuples.
  • Before swap: numbers1: 1, 2, 3 / numbers2: 4, 5, 6
  • After swap: numbers1: 4, 5, 6 / numbers2: 1, 2, 3

#include <iostream>
#include <tuple>
using namespace std;

int main() {
    tuple<int, int, int> numbers1(1, 2, 3);
    tuple<int, int, int> numbers2(4, 5, 6);
    numbers1.swap(numbers2);
    cout << get<0>(numbers1) << " " << get<0>(numbers2) << endl;
}

Unpacking a Tuple with tie()

  • The tie function unpacks a tuple and assigns its values to individual variables in a single statement.
  • Using ignore to Skip Values: Pass ignore as an argument to skip values you don't need

#include <iostream>
#include <string>
#include <tuple>
using namespace std;

int main() {
    tuple<int, char> gradeTuple(90, 'A');
    int testScore;
    char grade;
    tie(testScore, grade) = gradeTuple;
    // testScore is 90, grade is 'A'

    tuple<int, string, double> itemTuple(123, "USB Cable", 8.99);
    int itemNumber;
    string itemName;
    tie(itemNumber, itemName, ignore) = itemTuple;
    // Extracts only the int and string; skips the double
    cout << itemNumber << " " << itemName << endl;
}

Structured Binding Declarations

  • Perhaps the simplest way to unpack a tuple is with a structured binding declaration (C++17). It defines variables and initializes them from the tuple in a single statement.
  • Works with tuples of different types
  • Key Advantage: Structured bindings are shorter and cleaner than using tie() because you don't need to declare variables first.

#include <iostream>
#include <string>
#include <tuple>
using namespace std;

int main() {
    tuple<int, int, int> numbers(1, 2, 3);
    auto [num1, num2, num3] = numbers;
    // num1 is 1, num2 is 2, num3 is 3

    tuple<string, int, double> studentInfo{"Mateo", 20, 3.9};
    auto [name, age, gpa] = studentInfo;
    cout << name << " is " << age << " years old with a GPA of " << gpa << endl;
}

Returning a Tuple from a Function

  • Tuples are very useful when you need to return multiple values from a function. Package the values with make_tuple and return them.
  • Call the function and unpack the result with a structured binding (simplest) or with tie

#include <iostream>
#include <tuple>
using namespace std;

tuple<int, int, int> getTestScores()
{
    int score1 = 0, score2 = 0, score3 = 0;
    cout << "Enter three test scores: ";
    cin >> score1 >> score2 >> score3;
    return make_tuple(score1, score2, score3);
}

int main() {
    // Using structured binding (simplest)
    auto [test1, test2, test3] = getTestScores();
    // Using tie
    int t1, t2, t3;
    tie(t1, t2, t3) = getTestScores();
    cout << endl << test1 << " " << t1 << endl;
}

Comparing Tuples

  • Tuples can be compared using the standard comparison operators (==, !=, <, <=, >, >=). Elements are compared from left to right.
  • Equality (==): All corresponding elements must be equal for the tuples to be equal.
  • Other Comparisons (<, >, etc.): Compared element by element from left to right until a difference is found.

#include <iostream>
#include <string>
#include <tuple>
using namespace std;

int main() {
    tuple<int, string> student1(85, "Ahmed Hassan");
    tuple<int, string> student2(90, "Lisa Chen");
    tuple<int, string> student3(85, "Ahmed Hassan");
    if (student1 == student3)
        cout << "student1 and student3 are equal." << endl;
    if (student2 > student1)
        cout << "student2 is greater than student1." << endl;
}

Concatenating Tuples with tuple_cat

  • The tuple_cat function combines multiple tuples into a single tuple, preserving the order of all elements.
  • first (99, "Hello") + second (3.14, 'A') = combined (99, "Hello", 3.14, 'A')

#include <iostream>
#include <string>
#include <tuple>
using namespace std;

int main() {
    tuple<int, string> first(99, "Hello");
    tuple<double, char> second(3.14, 'A');
    auto combined = tuple_cat(first, second);
    // combined type: tuple<int, string, double, char>
    // combined holds: 99, "Hello", 3.14, 'A'
    cout << get<1>(combined) << " " << get<3>(combined) << endl;
}

19.7 Algorithms

Algorithms

  • STL algorithms are function templates that perform common operations on containers.
  • Min/max algorithms: Find smallest and largest values
  • Sorting algorithms: Sort or check if sorted
  • Search algorithms: Search sorted ranges
  • Read-only algorithms: Iterate without modifying
  • Modifying algorithms: Copy, move, transform elements
  • Most algorithms require the <algorithm> header file.

Common STL Algorithms

  • sort(): Sort elements in ascending order
  • find(): Search for a value
  • count(): Count occurrences of a value
  • reverse(): Reverse order of elements
  • min_element(), max_element(): Find min/max
  • binary_search(): Check if sorted range contains value
  • for_each(): Apply function to each element
  • transform(): Apply function and store results

min_element() and max_element()

  • These algorithms find the smallest and largest elements in a range:
  • Return iterators pointing to the minimum or maximum element
  • Must dereference the iterator to get the value
  • minmax_element() returns both min and max as a pair

#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

int main() {
    vector<int> values = {45, 46, 2, 47, 48, 999, 49, 50};
    // Find min and max
    auto min = min_element(values.begin(), values.end());
    auto max = max_element(values.begin(), values.end());
    cout << "Minimum: " << *min << endl;  // 2
    cout << "Maximum: " << *max << endl;  // 999
}

sort() and binary_search()

  • Sorting and searching are fundamental STL algorithms:
  • sort(): Sorts elements in ascending order (default)
  • binary_search(): Efficiently searches sorted ranges
  • Returns true if value found, false otherwise

#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {50, 10, 40, 20, 30};
    // Sort the vector
    sort(numbers.begin(), numbers.end());
    // numbers is now: {10, 20, 30, 40, 50}
    // Binary search (only works on sorted ranges)
    if (binary_search(numbers.begin(), numbers.end(), 30))
        cout << "Found 30!" << endl;
}

find() and count()

  • Search algorithms for locating values in containers:
  • find(): Returns iterator to first occurrence, or end() if not found
  • count(): Returns number of occurrences of a value
  • Work on unsorted ranges (unlike binary_search)

#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {10, 20, 30, 20, 40};
    // Find first occurrence of 20
    auto it = find(numbers.begin(), numbers.end(), 20);
    if (it != numbers.end())
        cout << "Item Found\n";
    // Count occurrences
    int occurrences = count(numbers.begin(), numbers.end(), 20);
    cout << "Found " << occurrences << " times"; // 2
}

remove() and reverse()

  • Modifying algorithms that rearrange container elements:
  • remove(): Moves unwanted elements to end, doesn't delete them
  • Must call erase() to actually delete
  • reverse(): Reverses the order of elements in a range

#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {1, 7, 3, 7, 4, 7, 5};
    // Remove all 7s (erase-remove idiom)
    auto newEnd = remove(numbers.begin(), numbers.end(), 7);
    numbers.erase(newEnd, numbers.end());
    // numbers is now: {1, 3, 4, 5}
    reverse(numbers.begin(), numbers.end());
    // numbers is now: {5, 4, 3, 1}
    for (int n : numbers)
        cout << n << " ";
}

19.8 Passing Functions to Algorithms

Passing Functions to Algorithms

  • Many STL algorithms can accept functions to customize their behavior.
  • Function Pointers: Pass regular function names
  • Function Objects (Functors): Objects that act like functions (covered in Chapter 20)
  • Lambda Expressions: Anonymous inline functions (covered in Chapter 20)

for_each() with Function Pointers

  • The for_each algorithm applies a function to each element in a range
  • displayAndDouble is passed as a function pointer

#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

// Function to display and modify each element
void displayAndDouble(int& num)
{
    cout << "Before: " << num << ", ";
    num *= 2;
    cout << "After: " << num << endl;
}

int main() {
    vector<int> numbers = {1, 2, 3, 4, 5};
    // Apply function to each element
    for_each(numbers.begin(), numbers.end(), displayAndDouble);
    // numbers is now: {2, 4, 6, 8, 10}
    return 0;
}

Using Predicates with Algorithms

  • Predicates are functions that return bool values, used with many algorithms

#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

// Predicate function - returns true if even
bool isEven(int num)
{
    return num % 2 == 0;
}

int main() {
    vector<int> numbers = {1, 2, 3, 4, 5, 6, 7, 8};
    // Count even numbers
    int evenCount = count_if(numbers.begin(), numbers.end(), isEven);
    cout << "Even numbers: " << evenCount << endl; // Output: 4
    // Find first even number
    auto it = find_if(numbers.begin(), numbers.end(), isEven);
    cout << "First even: " << *it << endl; // Output: 2
}

transform() with Function Pointers

  • The transform algorithm applies a function to each element and stores results

#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

// Function to square a number
int square(int num)
{
    return num * num;
}

int main() {
    vector<int> numbers = {1, 2, 3, 4, 5};
    vector<int> results(5);  // Destination vector
    // Transform each element and store in results
    transform(numbers.begin(), numbers.end(), results.begin(), square);
    // results is now: {1, 4, 9, 16, 25}
    for (int n : results)
        cout << n << " ";
    return 0;
}
